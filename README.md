
# GDG Frontend Task

Responsive portfolio website built using React, JavaScript, and CSS.

## Features

- Responsive design
- Dark and light mode
- Smooth animations
- Interactive navigation and FAQ

## Technologies

- React
- JavaScript (JSX)
- CSS
- Vite

## Setup

Install dependencies:

    npm install

Start the development server:

    npm run dev

Build for production:

    npm run build
